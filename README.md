Shizuku for Android 17

An experimental compatibility build of Shizuku intended to get Shizuku running on Android 17 while official upstream support is still in development.

This repository is unofficial and is not affiliated with or endorsed by the Shizuku developers. Changes are focused on Android 17 compatibility while preserving normal Shizuku functionality as much as possible.

Current status: Successfully starts shizuku_server on Android 17 with shell (UID 2000) privileges. Additional compatibility testing is ongoing.
